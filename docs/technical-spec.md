# MurderBoard 技术规格说明

MurderBoard 是面向探案推理小说笔记与桌游复盘的案件管理应用。本文档描述核心领域模型、数据规则与关键业务流程，作为后续产品设计、接口设计和实现的基础。

## 目标

- 支持按“剧本”组织多个案件。
- 支持记录人物、线索、事件、时间线与推理结论。
- 支持案件归档、恢复、删除撤销与回收站能力。
- 保证关键命名与时间字段具备一致的数据约束。

## 核心概念

### 剧本（Workspace）

剧本是最高层级的组织单元，用于聚合一个故事、桌游剧本或推理项目下的全部案件。

关键字段：

- `id`：唯一标识。
- `name`：剧本名称，同一用户或同一数据范围内必须唯一。
- `description`：剧本简介。
- `createdAt` / `updatedAt`：结构化日期时间。

### 案件（Case）

案件隶属于一个剧本，用于记录一次调查、一次游戏进程或一个独立推理分支。

关键字段：

- `id`：唯一标识。
- `workspaceId`：所属剧本标识。
- `name`：案件名称，在同一剧本下必须唯一。
- `status`：案件状态，例如草稿、进行中、已归档、已删除。
- `createdAt` / `updatedAt` / `archivedAt` / `deletedAt`：结构化日期时间。

### 人物（Character）

人物用于记录涉案角色、关系和嫌疑信息。

关键字段：

- `id`
- `caseId`
- `name`
- `role`
- `notes`

### 线索（Clue）

线索用于记录证据、证词、物品、地点发现或其他调查信息。

关键字段：

- `id`
- `caseId`
- `title`
- `content`
- `source`
- `discoveredAt`：结构化日期时间，可为空。

### 事件（Event）

事件用于构建时间线与因果链。

关键字段：

- `id`
- `caseId`
- `title`
- `description`
- `occurredAt`：结构化日期时间。
- `relatedCharacterIds`
- `relatedClueIds`

## 数据规则

### 命名唯一性

- 剧本名称不允许重复。
- 同一剧本下的案件名称不允许重复。
- 新建、重命名、归档恢复等流程都必须校验唯一性。
- 唯一性校验失败时，应提示用户选择新的名称，而不是静默覆盖已有数据。

### 时间字段

所有时间字段使用结构化日期时间值，不使用自由文本保存。

结构化日期时间至少应支持：

- 日期。
- 时间。
- 时区或明确的本地时间语义。
- 可序列化、可排序、可比较。

如果用户输入的是故事内时间线时间，应与系统记录时间区分存储，避免将现实操作时间和剧情事件时间混淆。

### 删除与恢复

删除操作不应立即不可逆地移除数据。

推荐状态流转：

1. 用户删除案件或内容。
2. 数据进入已删除状态并记录 `deletedAt`。
3. 用户可从撤销入口或回收站恢复。
4. 只有清空回收站或超过保留策略后，才允许执行不可恢复删除。

恢复时应重新校验命名唯一性。如果恢复目标名称已被占用，应要求重命名或自动生成可确认的新名称。

### 归档与恢复

归档用于隐藏不再活跃但仍需保留的案件。

归档恢复规则：

- 从归档恢复时，在当前剧本下创建一个新案件。
- 恢复出的新案件应保留原案件内容。
- 恢复出的新案件应重新生成案件标识。
- 恢复流程必须校验当前剧本下的案件名称唯一性。

## 关键业务流程

### 创建剧本

1. 用户输入剧本名称与简介。
2. 系统校验剧本名称唯一性。
3. 系统创建剧本并记录结构化创建时间。
4. 创建成功后进入剧本详情或案件列表。

### 创建案件

1. 用户在某个剧本下输入案件名称。
2. 系统校验该剧本下案件名称唯一性。
3. 系统创建案件并记录结构化创建时间。
4. 案件进入草稿或进行中状态。

### 删除案件

1. 用户触发删除。
2. 系统将案件标记为已删除并记录结构化删除时间。
3. 系统提供撤销入口。
4. 案件在回收站中可恢复或永久删除。

### 恢复归档案件

1. 用户选择要恢复的归档案件。
2. 系统以当前剧本为目标创建新案件。
3. 系统复制原案件内容并生成新的案件标识。
4. 系统校验并处理案件名称冲突。
5. 新案件进入当前剧本的案件列表。

## 后续实现建议

- 优先定义领域模型与持久化结构，再实现界面交互。
- 将软删除、归档、恢复作为领域服务处理，避免散落在界面层。
- 为命名唯一性、结构化时间、回收站恢复与归档恢复编写自动化测试。
- 在导入、复制、恢复等批量写入入口复用同一套校验逻辑。
