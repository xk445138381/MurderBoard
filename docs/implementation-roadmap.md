# MurderBoard 实现路线图

本文档将产品方向拆成开发 agent 可执行的阶段。当前主线是桌游玩家个人在游戏中使用的可视化推理案件板；归档、导入、复制等整理能力保留但降级。

## 阶段 1：设计基调与产品叙事

目标：把项目从通用案件管理对齐到玩家临场推理工具。

交付内容：

- 更新 PRD，明确首版 ICP 是桌游玩家个人使用。
- 新增 UI 设计方向和上线审查 gate。
- 明确主界面是 `Board`，不是 `Cases` 列表。
- 明确视觉基调是冷静调查桌面：深色工作台、浅色证据卡、克制状态色。

完成标准：

- 开发 agent 能按设计规范实现，不需要重新决定视觉方向。
- 上线审查有明确通过/不通过条件。

## 阶段 2：领域模型扩展

目标：支持案件板需要的一等对象和关系。

交付内容：

- 增加 `Hypothesis`，表示玩家猜想、嫌疑判断或待验证结论。
- 增加 `BoardRelation`，连接同一案件内的人物、线索、事件和猜想。
- 增加 `BoardNodePosition`，保存节点在案件板上的位置。
- 定义节点类型：`person`、`clue`、`event`、`hypothesis`。
- 定义关系类型：`related`、`supports`、`refutes`、`sequence`、`suspect`。

完成标准：

- 猜想可创建、编辑、软删除和查询。
- 关系只能连接同一案件内的有效节点。
- 节点位置可保存和恢复。
- 软删除节点后，关系查询和画布渲染不会崩溃。

## 阶段 3：可视化案件板 Shell

目标：先建立玩家能识别为 MurderBoard 的主界面。

交付内容：

- 新增 `Board` 默认入口。
- 布局采用顶部命令栏、左侧快速录入、中间画布、右侧 Inspector。
- 使用 `@xyflow/react` 或同等成熟节点画布方案实现可拖动节点和关系线。
- 先接 mock 或最小数据，再逐步接入 repository。
- 建立设计 token：背景、纸卡、边框、文字层级、焦点色、关系色、危险色。

完成标准：

- 第一屏是全屏案件板，不是表单列表。
- 桌面和平板宽度下画布占据主视觉。
- 四类节点视觉可区分。
- 关系线有语义颜色和状态。

## 阶段 4：快速录入和 Inspector

目标：让玩家在游戏中快速记内容，不被表单打断。

交付内容：

- 左侧快速录入支持人物、线索、事件和猜想。
- 创建节点只要求最少字段。
- 右侧 Inspector 编辑选中节点或关系的详细信息。
- 支持关系类型选择、编辑和删除。
- 支持搜索并定位画布节点。

完成标准：

- 玩家不用离开案件板即可创建节点和关系。
- 关键人物、线索、猜想或关系可在 10 秒内找回。
- Inspector 不遮挡画布，不造成布局跳动。

## 阶段 5：数据接入与现有页面降级

目标：把案件板接入现有本地数据，同时保留辅助管理能力。

交付内容：

- 将 `Board` 接入 IndexedDB repository。
- 现有 `Cases`、`Entities`、`Evidence`、`Timeline` 页面改为辅助入口或数据管理入口。
- 归档、回收站、导入、复制和移动保留，但不再作为首版核心推进。
- 修正默认测试扫描 `.worktrees` 的问题。

完成标准：

- 案件板刷新后保留节点和布局。
- 现有核心数据操作不回归。
- `npm test`、`npx vitest run src` 和 `npm run build` 通过。

## 阶段 6：上线前设计审查

目标：确认实现没有偏离“冷静调查桌面”和玩家临场使用。

交付内容：

- 提供桌面和平板截图或本地预览。
- 按设计审查 gate 检查视觉、布局、交互和文案。
- 修复审查中发现的阻断问题。

完成标准：

- 第一屏明确是推理案件板。
- 深色背景和浅色节点可读性合格。
- 快速录入、关系建立、搜索定位和 Inspector 流程顺手。
- 没有恐怖片化、营销页化或后台表单化倾向。

## 测试重点

- 猜想 CRUD 和软删除。
- 同一案件内关系校验。
- 节点位置保存与恢复。
- 删除节点后的关系安全处理。
- 搜索定位关键节点和关系。
- 案件板桌面和平板响应式布局。
- 深色背景下文字、关系线和焦点态对比度。
- 默认测试命令不扫描 `.worktrees`。

## 风险与注意事项

- 不要把案件板做成列表页里的一个小组件。
- 不要用长表单作为游戏中录入主路径。
- 不要把猜想当作事实或系统答案。
- 不要引入主持人真相、隐藏答案或多人协作。
- 不要让关系线只有装饰作用，必须能表达语义。
- 不要继续扩展归档、复制、导入，直到案件板核心体验成立。
