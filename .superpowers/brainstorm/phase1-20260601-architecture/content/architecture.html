阶段 1 架构设计：本地优先 React 应用骨架

目标是先建立可运行、可测试、可逐步扩展的前端工程，而不是一次性实现完整产品。

Proposed Architecture
App Shell
Vite + React + TypeScript
Router, layout, navigation
Feature Pages
Cases, entities, timeline
Placeholder screens first
Shared UI
Basic components
Empty/loading/error states
↓ user actions and route state
Domain Layer
Type definitions for case board data
Pure helpers where needed
Repository Layer
Storage interfaces used by features
Keeps UI independent from IndexedDB
↓ async persistence boundary
IndexedDB Adapter
Local-first persistence for future case boards, characters, locations, events, evidence, notes, and archive/trash metadata.

设计边界

阶段 1 只承诺工程骨架、路由、基础页面、数据访问抽象、IndexedDB 初始化和测试工具链。具体业务功能先以占位页和类型边界表达，避免过早实现未确认的交互。

A

架构方向正确

继续确认组件、数据流、错误处理和测试设计。

B

需要调整

比如改技术边界、减少数据层、或增加更完整的 UI 结构。
